# Peetri Pizza — браузерные автотесты (только для разработки, НЕ загружать на сервер)

`fake-session.php` подделывает вход и работает только под встроенным сервером PHP (`php -S`).

```
./serve.sh /путь/к/распакованному/релизу       # поднимает копию на 127.0.0.1:8099
node run-tests.js http://127.0.0.1:8099/peetripizza/ 17.1.0
```
Нужны PHP 8.1+, Node 18+ и `npm i playwright` (+ `npx playwright install chromium`).
9 тестов: ошибки JS, мигание при загрузке (медленный планшет), меню прячет очередь, запреты из handoff,
демо-заказы и таймеры, нагрузка таймера, LIVE (подменённый ответ) ок → обрыв, кнопки Statistika/Valmis, меню на планшете.
