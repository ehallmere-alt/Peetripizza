# v17.1 — стабилизация

База: v17.0.0 (последний архив пользователя). Дизайн главной не менялся, кроме двух согласованных кнопок в шапке.

## Что изменено в v17.1
1. **Мигание старой шапки при загрузке убрано.** В v17.0 защита прятала только список заказов, и на медленном планшете ~0,4 с была видна старая шапка (Statistika / Täisekraan / Uued / Töös / Koormus / Valmis (0)). Теперь до готовности скрыт весь каркас `.shell`; аварийное открытие через 3 с осталось (`boot-v170.js`).
2. **Секундный таймер больше не будит соседние скрипты.** Раньше каждое обновление таймера запускало цепочку `header-v132 → home-v157 → peetri-v160`, которые каждую секунду переписывали одинаковые значения. Теперь значения пишутся только при изменении, а `peetri-v160` / `peetri-v164` игнорируют изменения цифр таймера. Перерисовок `peetri-v160` за 10 с: было ~23, стало ~1–2. Таймеры, цвета KIIRE / HILINENUD и счётчики работают как раньше.
3. **Кнопки Statistika и Valmis (N) в новой шапке** (согласовано). Используют существующие обработчики: пункт меню Statistika и родную кнопку истории `#toggleHistory`. На планшете — иконка + число, на телефоне скрыты (Statistika есть в меню, Valmis — кнопка «Kõik valmis»). Файлы: `assets/header-v171.js`, `assets/header-v171.css`.
4. **Исправлено обрезание шапки на iPad вертикально (768 px):** кнопка звука уходила за край экрана.
5. **Установщик с резервной копией и откатом:** `tools/deploy.sh`.
6. `tools/.htaccess` закрывает папку `tools/` из браузера (PHP CLI работает как раньше).

## Не менялось
LIVE (только чтение), заказы, статусы, таймеры, печать 80 мм, Taigna tellimine, Tooted, Boonused (внешняя ссылка), меню, авторизация, API.

## Установка (SSH)
```
cd /www/apache/domains/www.crestudio.ee
unzip -o -j peetri-pizza-v17.1-release.zip tools/deploy.sh -d /tmp/peetri-deploy
bash /tmp/peetri-deploy/deploy.sh peetri-pizza-v17.1-release.zip
```
Скрипт сам делает резервную копию (`/www/apache/domains/www.crestudio.ee/peetri-backups/`, вместе с `private_data` и внешними конфигами), распаковывает, проверяет и при ошибке откатывает.

Откат вручную: `bash htdocs/peetripizza/tools/deploy.sh --rollback`
Список копий: `bash htdocs/peetripizza/tools/deploy.sh --list`

После установки: обновить страницу на планшетах без кеша, проверить меню, Statistika / Valmis в шапке, LIVE, печать, тесто.

**Важно:** откат не трогает `private_data`, поэтому статусы и заказы теста, сохранённые после обновления, остаются.
