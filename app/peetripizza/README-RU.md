# Peetri Pizza Service App v17.0 — стабильная передача

База: реальная установленная версия v16.9.2 из `peetripizza-current-code.zip`, с исправлением v16.9.3.

## Что изменено в v17.0
- Единая версия `17.0.0` в meta и меню; актуализированы query-параметры CSS.
- Защита первого отображения `boot-v170.js`: старый PHP-каркас не мелькает, пока JavaScript собирает утверждённую главную; при ошибке экран разблокируется через 3 секунды.
- Жёсткое скрытие неактивных разделов без изменения оформления карточек.
- Локальная безопасная диагностика `php tools/v17-smoke-check.php` и контроль хешей `php tools/release-check.php`.
- Удалены только неиспользуемые в архиве копии конфигурационных файлов (`.bak`, `.backup*`), **не серверные данные**.

## Не менялось
- Дизайн главной, кнопка LIVE, Ooteaeg наверху, меню, таймеры, статусы, печать, тесто.
- LIVE только читает upstream API; локальные статусы не записываются в официальную систему Peetri Pizza.
- Клиентская программа бонусов по внешней ссылке https://peetripizza.ee/bonus/; смены отсутствуют.

## Установка
1. Сохранить текущий сайт и данные отдельно.
2. Загрузить ZIP в `/www/apache/domains/www.crestudio.ee`.
3. Распаковать `unzip -o peetri-pizza-v17.0-release.zip -d htdocs/peetripizza/`.
4. Проверить `cd htdocs/peetripizza && php tools/release-check.php && php tools/v17-smoke-check.php`.
5. Перезагрузить страницу без кеша; проверить меню, заказы, LIVE, Tooted, Taigna tellimine, печать.

**Важно:** распаковка поверх не удаляет старые файлы, а проверки не подтверждают работу реальной интеграции. Не удалять `private_data`, внешние файлы авторизации, секреты и резервные копии.

Описание для передачи разработчику Claude: `CLAUDE-HANDOFF.md`.
